**WinNet-Toolkit** — бесплатный open-source набор утилит на PowerShell для комплексной сетевой диагностики, автономного обхода SNI/TLS-блокировок, защиты DNS и автоматического самовосстановления соединения в Windows 10 и Windows 11.

---

## ⚡ Быстрый старт (установка в 2 шага)

1. **Скачайте и распакуйте проект.**  
   Нажмите зеленую кнопку **Code** ➔ **Download ZIP** на странице репозитория и распакуйте архив в любую папку без кириллицы в пути (например, `D:\WinNet-Toolkit`).  
   > 💡 **Опционально (профили маршрутизации):** если вам нужен готовый `.yaml` или `.conf` конфиг, его можно бесплатно сгенерировать через Telegram-бота **[@warp_generator_bot](https://t.me)** и положить в папку с тулкитом перед установкой — скрипт импортирует его автоматически.

2. **Запустите `Setup.bat` двойным кликом мыши.**  
   Подтвердите запрос прав Администратора (UAC). После установки автоматически откроется панель управления `winnet`: выберите **пункт `1` (Автонастройка в 1 клик)**.

## 🚀 Основные возможности v3.2

* 🧠 **Автономный DPI-контроллер (`dpi-engine.ps1`):** обходит фильтрацию TCP/TLS (SNI) и UDP для Telegram, Discord (включая голосовые каналы) и YouTube «из коробки» без платных подписок.
* 🔄 **Фоновый Watchdog и автозапуск (`watchdog.ps1`):** служба в Планировщике заданий Windows (`SYSTEM`) контролирует качество связи с защитой от дублей (Global Mutex) и экспоненциальной задержкой повторов (Exponential Backoff), автоматически восстанавливая работу после сбоев и перезагрузки ПК.
* 🔍 **5-ступенчатая диагностика (`netcheck`):** проверка локальных модулей и профилей, определение внешнего IP и провайдера, аудит DNS (IPv4 + IPv6), проверка TLS Handshake и замер задержки (Ping).
* 🌐 **Оптимизация браузеров и чистые DNS (`Set-CleanDNS`, `Optimize-YouTubeStream`):** перевод адаптера на публичные DNS (`1.1.1.1`, `8.8.8.8`, `2606:4700:4700::1111`, `2001:4860:4860::8888`) и отключение протокола QUIC (`QuicAllowed = 0`) в Chromium-браузерах.
* ↩️ **Безопасный откат (`Restore-NetworkState` / Rollback):** перед изменением настроек создается резервная копия `network-backup.json`. Вернуть исходные параметры Windows можно в любой момент через **пункт `9`** меню `winnet`.

## 💻 Команды управления

После установки команды доступны из любой консоли (`PowerShell`, `CMD`, `Windows Terminal`):

| Команда | Описание |
| :--- | :--- |
| **`winnet`** | Открыть интерактивную панель управления (автонастройка в 1 клик, управление DPI-ядром, автозапуском Watchdog, профилями и откатом). |
| **`netcheck`** | Запустить полную 5-ступенчатую диагностику сетевого соединения. |

## 🔒 Безопасность и тестирование

* **Верификация целостности:** загружаемые модули и бинарные зависимости проверяются по контрольным суммам **SHA256** (`checksums.sha256`).
* **Изоляция и отсутствие открытых портов:** утилита работает исключительно на уровне локального сетевого стека (*Zero Open Ports*) с включенным строгим режимом `Set-StrictMode -Version Latest`.
* **Автоматические тесты:** проект покрыт модульными и синтаксическими тестами **Pester** (`Tests/WinNet.Tests.ps1`).
