# WinNet-Toolkit — Стабильный доступ к Telegram, YouTube и Discord без потери пинга

![PowerShell](https://shields.io)
![Windows](https://shields.io)
![Security](https://shields.io)
![Cost](https://shields.io)

**Бесплатный, открытый и безопасный инженерный инструмент на PowerShell для Windows 10/11.** Настраивает сетевой стек, защищает от подмены DNS, ускоряет видеопоток и разворачивает локальную маршрутизацию трафика так, чтобы заблокированные сервисы летали, а онлайн-игры и сайты РФ работали на максимальной скорости провайдера.

---

## Знакомая проблема? Вы по адресу

* **Telegram Desktop** вечно висит на `Connecting...` или `Loading...`, не грузит голосовые и файлы.
* **YouTube** открывается через раз, видео зависает на черном экране или грузится только в 144p.
* **Discord** не подключается к голосовым каналам (`RTC Connecting`) или не запускает клиент.
* **Обычные VPN** режут скорость интернета, ломают пинг в CS2 / Dota 2 и заставляют отключать их ради банков и Госуслуг.

**WinNet-Toolkit** решает все 4 проблемы комплексно за 2 минуты — локально, прозрачно и без платных подписок.

---

## Как это работает (Архитектура без костылей)

Вместо тяжелых коммерческих VPN-клиентов тулкит использует трехслойную инженерную схему:

1. **Оптимизация стека ОС (`Set-CleanDNS` + `Optimize-YouTubeStream`):** убирает подмену DNS со стороны провайдера (перевод на `1.1.1.1` / `8.8.8.8`) и принудительно отключает протокол UDP/QUIC в Chromium-браузерах (`QuicAllowed=0`), переводя видеопоток YouTube на стабильный TCP/TLS.
2. **Умный локальный маршрутизатор (`Clash Verge Rev + TUN Mode`):** устанавливается одним кликом из меню. Поднимает системный виртуальный адаптер, который перехватывает трафик **Telegram, YouTube и Discord** (включая UDP-звонки), оставляя игровой и российский трафик напрямую.
3. **Консольный аудит (`netcheck`):** встроенная 5-ступенчатая диагностика за 2 секунды показывает статус туннеля, реальный IP, наличие DNS-спуфинга, статус TLS Handshake и пинг.

## Установка и запуск за 60 секунд

### Шаг 1. Запустите установщик в 1 команду
1. Нажмите **`Win + X`** и выберите **Терминал (Администратор)** или **Windows PowerShell (Администратор)**.
2. Вставьте команду ниже и нажмите **`Enter`**:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force; [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm https://raw.githubusercontent.com/allinvvs/WinNet-Toolkit/main/install.ps1 | iex
```

### Шаг 2. Настройте систему через интерактивное меню
После установки введите в консоли слово **`winnet`**:
* Нажмите **`2`** — очистит DNS и ускорит YouTube (затем перезапустите браузер).
* Нажмите **`3`** — автоматически скачает и установит клиент **Clash Verge Rev**.
* *(Опционально)* Нажмите **`4`** — подключит экстренный резервный прокси в Telegram, если нужно зайти за конфигом.

### Шаг 3. Подключите бесплатный профиль маршрутизации (`.yaml`)
1. Сгенерируйте бесплатный конфиг формата **Clash (`.yaml`)** через любой WARP-генератор в Telegram (например, `@warp_generator_bot`).
2. Откройте **Clash Verge** -> вкладка **Профили** -> кнопка **НОВЫЙ** -> *Тип*: **Local** -> выберите скачанный `.yaml` файл -> **Сохранить** и кликните по карточке профиля для активации.
3. Перейдите в **Настройки** -> нажмите шестеренку напротив **Режим TUN** -> **Service Mode** -> **Install**, затем включите сам переключатель **Режим TUN** и **Автозапуск** (*Auto Launch*).
4. В настройках **Telegram Desktop** оставьте *Использовать системные настройки прокси* (или *Без прокси*).

## Что работает, а что нет (Честная матрица)

| Направление / Функция | Статус | Детали |
| :--- | :---: | :--- |
| **Telegram (Desktop & Web)** | Работает | Мгновенная загрузка чатов, медиа, кружков и звонков |
| **YouTube (4K / 60fps)** | Работает | Стабильный видеопоток без буферизации и черного экрана |
| **Discord (Чаты & Голос)** | Работает | Стабильный голос в каналах благодаря системному TUN-адаптеру |
| **Онлайн-игры и сайты РФ** | Работает | Прямой маршрут через провайдера без увеличения пинга |
| **Chrome, Edge, Яндекс.Браузер** | Работает | Полная поддержка политик оптимизации QUIC |
| **Mozilla Firefox** | Ограничено | Отключение QUIC нужно сделать вручную в `about:config` |
| **Работа без файла-ключа (`.yaml`)** | Не поддерживается | Тулкит настраивает систему и клиент, но сам ключ генерируется пользователем |
| **macOS / Linux / Android / iOS** | Не поддерживается | Инструмент разработан нативно под Windows 10 и Windows 11 |

## Безопасность и стандарты кода

* **Zero Open Ports:** скрипты не открывают ни одного входящего порта на вашем ПК.
* **StrictMode & Validation:** используется `Set-StrictMode -Version Latest`, проверка прав администратора и контроль целостности скачиваемых файлов.
* **Open Source:** весь код открыт для аудита в файле `netcheck.ps1`. Никакой телеметрии, рекламы и скрытых служб.
