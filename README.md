Надежный и безопасный набор инструментов на PowerShell для диагностики сети, защиты от DNS-спуфинга, оптимизации видеопотока **YouTube** и быстрого развертывания локальной маршрутизации для стабильной работы **Telegram, YouTube и Discord** без костылей и постоянных патчей.

---

## Быстрый старт (Установка в 1 команду)

1. Нажмите **`Win + X`** и выберите **Терминал (Администратор)** или **Windows PowerShell (Администратор)**.
2. Вставьте команду ниже и нажмите **`Enter`**:

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm https://raw.githubusercontent.com/allinvvs/WinNet-Toolkit/main/install.ps1 | iex
```

3. После установки в любом окне терминала доступны две команды:
   * **`winnet`** — открывает интерактивное меню управления (`1–4`).
   * **`netcheck`** — запускает 5-ступенчатую диагностику сети, туннеля и задержек.

## Стратегия настройки «под ключ» (Telegram + YouTube + Discord)

Чтобы сервисы работали стабильно и автоматически поднимались после перезагрузки ПК:

1. **Оптимизируйте стек Windows:** запустите **`winnet`** и выберите пункт **`2`** (перевод основного адаптера на чистые DNS `1.1.1.1` / `8.8.8.8` и отключение протокола QUIC в Chromium-браузерах для стабильного 4K на YouTube).
2. **Установите клиент маршрутизации:** в меню **`winnet`** выберите пункт **`3`** — скрипт автоматически скачает и установит свежий **Clash Verge Rev** (с проверкой целостности файла).
3. **Подключите профиль маршрутизации (`.yaml`):**
   * Получите бесплатный профиль формата **Clash (`.yaml`)** в любом актуальном WARP-генераторе в Telegram (например, `@warp_generator_bot`).
   * В **Clash Verge** перейдите во вкладку **Профили** -> **Новый** -> **Local**, выберите скачанный `.yaml` файл и активируйте карточку профиля кликом.
4. **Включите системный туннель (TUN Mode):**
   * В **Clash Verge** откройте **Настройки** -> нажмите шестеренку рядом с **Режим TUN** -> **Service Mode** -> **Install**, затем включите переключатель **TUN Mode**.
   * В настройках **Telegram Desktop** оставьте режим *Use system proxy settings* (или *Disable proxy*).

## Инженерные гарантии и безопасность

* **Zero Open Ports:** скрипты не открывают ни одного входящего TCP/UDP-порта на хосте.
* **StrictMode & Validation:** включен строгий режим PowerShell (`Set-StrictMode -Version Latest`), проверка прав администратора и контроль размера скачиваемых пакетов.
* **Безопасный предпросмотр:** системные функции (`Set-CleanDNS`, `Optimize-YouTubeStream`) поддерживают стандартный флаг `-WhatIf`.
