# WinNet-Toolkit

> **Платформа:** Windows 10 / 11 | **Язык:** PowerShell 5.1+ | **Безопасность:** Zero Open Ports | **Лицензия:** MIT

**WinNet-Toolkit** — открытый набор утилит на PowerShell для комплексной сетевой диагностики, аудита DNS и TLS-соединений, оптимизации транспортных протоколов браузеров и автоматизации настройки локальной маршрутизации в Windows 10 и Windows 11.

---

## Основные возможности

* **Консольная диагностика (`netcheck`):** 5-ступенчатый аудит сетевого стека — проверка состояния виртуальных сетевых адаптеров, определение внешнего IP и провайдера (ISP) по HTTPS, проверка корректности DNS-резолвинга, аудит TLS Handshake до веб-узлов и замер задержки (Ping).
* **Настройка публичных DNS (`Set-CleanDNS`):** перевод основного сетевого интерфейса на стандартные публичные DNS-серверы Cloudflare (`1.1.1.1`) и Google (`8.8.8.8`) с очисткой системного кэша.
* **Оптимизация транспортного уровня браузеров (`Optimize-YouTubeStream`):** управление политикой `QuicAllowed = 0` для Chromium-браузеров (Chrome, Edge, Яндекс.Браузер) с целью стабилизации потокового видео по классическому TCP/TLS при нестабильной работе UDP.
* **Автоматизация развертывания (`Install-ClashClient`):** загрузка и установка клиента локальной маршрутизации **Clash Verge Rev** из официального репозитория GitHub с проверкой целостности установочного пакета.

## Установка и запуск

### 1. Установка модуля
1. Нажмите **`Win + X`** и откройте **Терминал (Администратор)** или **Windows PowerShell (Администратор)**.
2. Выполните следующую команду:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force; [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm https://raw.githubusercontent.com/allinvvs/WinNet-Toolkit/main/install.ps1 | iex
```

3. После завершения установки в консоли доступны две команды:
   * **`winnet`** — запуск интерактивного консольного меню.
   * **`netcheck`** — запуск полной диагностики сетевого соединения.

### 2. Базовая настройка локальной маршрутизации
1. Запустите **`winnet`** и выберите пункт **`2`** для настройки DNS и политик браузера (после выполнения перезапустите браузер).
2. Выберите пункт **`3`** для автоматической установки клиента **Clash Verge Rev**.
3. Импортируйте пользовательский файл конфигурации (`.yaml`) во вкладке **Профили** -> **Новый** -> **Local** и активируйте его.
4. Во вкладке **Настройки** активируйте системный виртуальный адаптер (**Режим TUN** -> шестеренка -> **Service Mode** -> **Install**, затем включите переключатель **Режим TUN**) и при необходимости включите **Автозапуск**.

## Совместимость и системные требования

| Компонент / Функция | Статус | Техническое примечание |
| :--- | :---: | :--- |
| **Windows 10 / Windows 11** | Поддерживается | Требуется PowerShell версии 5.1 или выше |
| **Chromium-браузеры** | Поддерживается | Управление групповыми политиками QUIC (Chrome, Edge, Яндекс.Браузер) |
| **Mozilla Firefox** | Ограничено | Настройка протокола HTTP/3 (QUIC) выполняется пользователем в `about:config` |
| **Системная маршрутизация (TUN)** | Поддерживается | Требует пользовательский конфигурационный файл формата `.yaml` |
| **macOS / Linux** | Не поддерживается | Утилита использует специфичные командлеты сетевого стека Windows (`NetTCPIP`, `DnsClient`) |

## Архитектура безопасности и отказ от ответственности

* **Zero Open Ports:** утилита не открывает входящих сетевых портов на устройстве пользователя.
* **StrictMode & Validation:** в коде используется строгий режим выполнения (`Set-StrictMode -Version Latest`), проверка прав администратора перед изменением системных параметров и верификация размера загружаемых файлов.
* **Дисклеймер:** программное обеспечение предоставляется «как есть» (AS IS) согласно лицензии MIT и предназначено исключительно для диагностики сетей, администрирования локальных рабочих станций и оптимизации сетевых протоколов.
