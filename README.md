# WinNet-Toolkit

Инженерный набор инструментов на PowerShell для сетевой диагностики, аудита блокировок (DNS/SNI), оптимизации сетевого стека Windows 10/11 и автономного управления десинхронизацией TLS/QUIC.

## Возможности проекта
- **`netcheck` (`Invoke-NetCheck`)** — 4-ступенчатая диагностика сети: проверка внешнего IP/ISP, обнаружение DNS-спуфинга, аудит HTTPS (TLS Handshake) и замер задержки (Ping).
- **`Start-DpiEngine` / `Stop-DpiEngine`** — автономный контроллер десинхронизации пакетов с имитацией TLS ClientHello и системным шифрованием DNS-over-HTTPS (DoH) для стабильной работы **Telegram, YouTube и Discord**.
- **`Optimize-YouTubeStream`** — отключение протокола QUIC (`QuicAllowed = 0`) в Chromium-браузерах для предотвращения деградации видеопотока.
- **`Set-CleanDNS`** — безопасный перевод основного сетевого интерфейса на чистые DNS (`1.1.1.1`, `8.8.8.8`) с поддержкой `-WhatIf`.
- **`Export-SplitRoutes`** — генератор JSON-правил раздельного туннелирования (Split Tunneling) для маршрутизаторов на базе **Sing-box**.

## Архитектура безопасности
- **Zero Open Ports:** движок не открывает входящих TCP/UDP-портов на хосте.
- **Strict Hostlist:** обработка пакетов применяется строго к целевым доменам (`targets.txt`), оставляя банковский, игровой и локальный трафик напрямую в штатном стеке ОС.
- **No Persistent SYSTEM Services:** работает исключительно в пользовательской сессии без установки скрытых фоновых служб.

## Быстрый старт

```powershell
git clone https://github.com
cd WinNet-Toolkit

# Подключение модуля диагностики и оптимизации
. .\netcheck.ps1
netcheck

# Запуск автономного DPI-контроллера (требуются права Администратора)
. .\dpi-engine.ps1
Start-DpiEngine
```
